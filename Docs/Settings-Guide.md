# RimAI 설정 가이드

RimAI 모드의 설정 시스템을 통해 "관람용 방치 플레이"를 완벽하게 제어할 수 있습니다.

## 설정 메뉴 접근 방법

1. RimWorld 메인 메뉴 또는 게임 내에서 **옵션(Options)** 선택
2. **모드 설정(Mod Settings)** 탭 클릭
3. 목록에서 **RimAI - Auto Pilot** 선택

## 빠른 프리셋

바로 시작하고 싶다면 상단의 프리셋 버튼을 클릭하세요:

### 1. 완전 방치 관람 (Full Auto)

**추천 사용자**: 진짜 관람만 하고 싶은 분
- **모든 자동화**: 최대
- **식량 관리**: 농사, 사냥, 요리 모두 적극 자동화
- **건설/확장**: 침대, 인프라, 방어 시설 자동 건설
- **연구 선택**: 콜로니 상황에 맞는 연구 자동 선택
- **전투 대응**: 적 습격 시 자동 징집 및 전투
- **시네마틱 카메라**: ON (전투 시 자동 추적)
- **로그**: 일반 (주요 이벤트만)

**이렇게 사용하세요**:
```
게임 시작 → 프리셋 "완전 방치 관람" 클릭 → 그냥 관람하기
```

### 2. 위기만 자동 대응 (Crisis Only)

**추천 사용자**: 건설/연구는 직접 하고, 생존만 맡기고 싶은 분
- **식량 관리**: 높음 (생존 보장)
- **건설/확장**: 낮음 (긴급 상황만, 예: 침대 부족)
- **연구 선택**: 낮음 (드물게 선택)
- **전투 대응**: 높음 (적극 방어)
- **시네마틱 카메라**: ON
- **로그**: 일반

**이렇게 사용하세요**:
```
직접 플레이하면서 + RimAI가 위기 상황만 자동 처리
```

### 3. 디버그 모드 (Debug)

**추천 사용자**: 개발자, 모드 테스트, 디버깅
- **모든 자동화**: 최대 + 매우 빠름
- **로그**: 디버그 (모든 결정 과정 출력)

## 세부 설정

### 마스터 스위치

**전체 자동화 활성화**: 모든 RimAI 기능을 한 번에 ON/OFF

이 스위치를 끄면 RimAI가 완전히 비활성화되고, 바닐라 RimWorld처럼 작동합니다.

### 서브시스템별 개입 강도

각 자동화 영역의 강도를 개별적으로 조절할 수 있습니다:

#### 강도 레벨 설명

| 강도 | 설명 | 업데이트 빈도 | 행동 패턴 |
|------|------|---------------|-----------|
| **OFF** | 비활성화 | - | 해당 서브시스템 완전 비활성화 |
| **낮음 (Low)** | 최소 개입 | 3배 느림 | 긴급 상황만 대응 |
| **중간 (Medium)** | 일반 개입 | 1.5배 느림 | 필요할 때 대응 |
| **높음 (High)** | 적극 개입 | 정상 속도 | 적극적으로 최적화 |
| **최대 (Full)** | 완전 자동화 | 2배 빠름 | 모든 결정을 AI가 처리 |

#### 1. 식량 관리 (Food Management)

**무엇을 자동화하나요?**
- 농사 (파종, 수확)
- 사냥 우선순위
- 요리 작업량 조절

**개입 강도 예시**:
- **낮음**: 식량이 3일치 미만으로 떨어질 때만 긴급 농사/사냥
- **높음**: 계절에 맞춰 미리 대비, 겨울 전 식량 비축
- **최대**: 완벽한 식량 관리, 여유분 항상 유지

**권장 설정**: 높음 (생존은 중요하니까!)

#### 2. 건설/확장 (Construction)

**무엇을 자동화하나요?**
- 침대 부족 시 자동 건설
- 기본 인프라 (주방, 창고)
- 방어 시설 (샌드백 등)

**개입 강도 예시**:
- **낮음**: 콜로니스트가 노숙할 위기에만 침대 건설
- **높음**: 여유 침대 확보, 방어 시설 적극 건설
- **최대**: 완벽한 인프라 계획 및 건설

**권장 설정**: 중간 또는 높음

**참고**: 실제 청사진 배치는 아직 구현되지 않았습니다. 현재는 로그로 "건설 필요" 알림만 제공합니다.

#### 3. 연구 선택 (Research)

**무엇을 자동화하나요?**
- 콜로니 상황에 맞는 연구 프로젝트 자동 선택
- 식량/의료/전기/방어 등 휴리스틱 기반 우선순위

**개입 강도 예시**:
- **낮음**: 연구 없을 때만 드물게 선택
- **높음**: 적극적으로 최적 연구 선택
- **최대**: 매우 빠르게 다음 연구 선택 (거의 즉시)

**권장 설정**: 중간 (연구는 천천히 해도 괜찮아요)

#### 4. 전투 대응 (Combat)

**무엇을 자동화하나요?**
- 적 습격 감지
- 자동 징집 (Draft)
- 전투 종료 시 자동 해제 (Undraft)
- 시네마틱 카메라로 전투 추적

**개입 강도 예시**:
- **낮음**: 큰 위협만 대응 (적 10명 이상)
- **높음**: 모든 위협에 즉시 대응
- **최대**: 매우 민감하게 반응, 빠른 전투 개시

**권장 설정**: 높음 (전투는 빠른 반응이 중요!)

**참고**: 실제 전투는 RimWorld 바닐라 AI가 처리합니다. RimAI는 "언제 싸울지"만 결정합니다.

### 카메라 설정

**시네마틱 카메라 활성화**:
- **ON**: 전투 시 카메라가 자동으로 전장으로 이동 + 줌인
- **OFF**: 카메라 이동 없음, 직접 조작 필요

**관람 모드**라면 ON 추천!

### 로그 상세도

게임 로그(화면 왼쪽 하단)에 출력되는 RimAI 메시지 양을 조절합니다:

| 레벨 | 출력 내용 | 언제 사용? |
|------|-----------|-----------|
| **최소 (Minimal)** | 오류/경고만 | 로그 깔끔하게 유지하고 싶을 때 |
| **일반 (Normal)** | 주요 이벤트 | **권장** - 무슨 일이 일어나는지 알고 싶을 때 |
| **상세 (Detailed)** | 모든 결정 | RimAI가 무슨 생각하는지 궁금할 때 |
| **디버그 (Debug)** | 개발자 정보 | 모드 개발/디버깅할 때만 |

**권장 설정**: 일반


## FAQ

### Q: 설정을 바꾸면 언제 적용되나요?

**A**: 즉시 적용됩니다. 게임을 재시작할 필요 없습니다.

### Q: 프리셋을 선택하면 내 설정이 사라지나요?

**A**: 네. 프리셋은 모든 설정을 덮어씁니다. 세부 설정을 직접 조정하면 프리셋이 "Custom"으로 변경됩니다.

### Q: 여러 설정을 동시에 끄려면?

**A**: "전체 자동화 활성화" 스위치를 끄면 RimAI 전체가 비활성화됩니다.

### Q: 게임 중간에 설정을 바꿔도 되나요?

**A**: 네! 언제든지 바꿀 수 있습니다. 예를 들어 평시에는 "중간", 대규모 습격 전에는 "최대"로 바꾸는 식으로 사용할 수 있습니다.

### Q: 로그가 너무 많이 나와요!

**A**: 로그 레벨을 "일반" 또는 "최소"로 낮추세요.

### Q: 특정 서브시스템만 완전히 끄려면?

**A**: 해당 서브시스템의 강도를 "OFF"로 설정하세요.

### Q: RimAI 없이 바닐라로 플레이하고 싶어요

**A**: "전체 자동화 활성화" 체크 해제 → 완전 바닐라 모드

## 성능 관련

**Q: 설정이 게임 성능에 영향을 주나요?**

**A**: 약간의 영향이 있습니다:
- **낮음 (Low)**: 가장 가벼움 (업데이트 빈도 낮음)
- **중간 (Medium)**: 적당함
- **높음 (High)**: 정상 (거의 눈에 띄지 않음)
- **최대 (Full)**: 약간 무거울 수 있음 (업데이트 2배 빠름)

일반적으로 **"높음"까지는 성능 문제 없습니다**. "최대"는 정말 완벽한 자동화가 필요할 때만 사용하세요.

## 개발자를 위한 참고사항

### 설정 파일 위치

설정은 RimWorld 세이브 폴더에 자동 저장됩니다:
```
[RimWorld 설치 경로]/Config/ModSettings/RimAI.xml
```

### 코드에서 설정 참조

```csharp
// 설정 참조
var settings = RimAI_Mod.Settings;

// 특정 서브시스템 활성화 여부
bool isEnabled = settings.IsSubsystemEnabled("Food");

// 개입 강도 가져오기
AutomationIntensity intensity = settings.GetIntensity("Combat");

// 로그 출력 여부 확인
if (settings.ShouldLog(LogLevel.Detailed))
{
    Log.Message("상세 로그 메시지");
}

// 업데이트 간격 배수
float multiplier = RimAISettings.GetUpdateIntervalMultiplier(intensity);
int adjustedInterval = (int)(baseInterval * multiplier);
```

### 새 서브시스템 추가 시

`RimAISettings.GetIntensity()` 메서드에서 새 서브시스템 이름을 처리하도록 switch 문을 업데이트하세요.
