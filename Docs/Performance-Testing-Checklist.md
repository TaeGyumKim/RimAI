# RimAI - 장시간 플레이 테스트 체크리스트

## 개요
RimAI 모드의 장시간 안정성과 성능을 검증하기 위한 테스트 체크리스트입니다.
"수십 시간 방치 플레이"를 목표로 하므로 메모리 누수, 성능 저하, AI 이상 동작을 중점적으로 확인합니다.

---

## 📋 테스트 환경 설정

### 기본 설정
- [ ] **RimWorld 버전**: 1.4 또는 1.5
- [ ] **다른 모드**: 최소화 (Harmony만 활성화)
- [ ] **맵 크기**: 중형 (250x250) 또는 대형 (300x300)
- [ ] **난이도**: Rough 이상
- [ ] **스토리텔러**: Randy Random (예측 불가능한 이벤트)
- [ ] **시작 시나리오**: Crashlanded (3명 시작)
- [ ] **RimAI 설정**: "완전 방치 관람" 프리셋

### 모니터링 도구 준비
- [ ] 작업 관리자 / Task Manager (메모리/CPU 모니터링)
- [ ] Player.log 파일 위치 확인
- [ ] 스크린샷/동영상 녹화 준비 (이상 동작 기록용)

## ⏱️ 단계별 테스트 (누적 시간)

### 1단계: 초기 안정성 (0-2시간)

#### 성능 체크
- [ ] **게임 시작 후 FPS**: _____ (60 근처 유지되는지)
- [ ] **1시간 후 FPS**: _____ (저하 없는지)
- [ ] **2시간 후 FPS**: _____ (저하 없는지)
- [ ] **메모리 사용량 (시작 시)**: _____ MB
- [ ] **메모리 사용량 (1시간 후)**: _____ MB
- [ ] **메모리 사용량 (2시간 후)**: _____ MB
  - ⚠️ **경고**: 시간당 50MB 이상 증가하면 메모리 누수 의심

#### AI 동작 체크
- [ ] 식량 자동화 작동 확인 (농사/사냥/요리)
- [ ] 건설 자동화 작동 확인 (침대/인프라)
- [ ] 연구 자동 선택 작동 확인
- [ ] 전투 자동 대응 작동 확인 (레이드 발생 시)
- [ ] 콜로니스트가 idle 상태로 멈춰있지 않은지

#### 로그 체크
- [ ] Player.log에 반복적인 에러 없는지
- [ ] RimAI 로그가 정상적으로 출력되는지
- [ ] 프레임 저하 경고 없는지

### 2단계: 중기 안정성 (2-6시간)

#### 성능 체크
- [ ] **4시간 후 FPS**: _____ (초기 대비 10% 이상 저하 시 문제)
- [ ] **6시간 후 FPS**: _____ (초기 대비 15% 이상 저하 시 문제)
- [ ] **메모리 사용량 (4시간)**: _____ MB
- [ ] **메모리 사용량 (6시간)**: _____ MB
  - ⚠️ **경고**: 1GB 초과 증가 시 메모리 누수 확실

#### 틱 지연 (Tick Lag) 체크
- [ ] 게임 속도 3배속 유지 가능한지
- [ ] 간헐적인 렉/프리징 발생하지 않는지
- [ ] 대규모 레이드 (10명 이상) 시 버벅임 정도: _____
  - ✅ 정상: 약간 느려지지만 플레이 가능
  - ⚠️ 문제: 1초 이상 멈춤 또는 크래시

#### AI 이상 동작 체크
- [ ] 콜로니스트가 무한 루프에 빠지지 않는지
- [ ] 식량 생산/소비 균형이 유지되는지
- [ ] 건설 작업이 중복 계획되지 않는지
- [ ] 전투 시 Draft가 정상적으로 해제되는지
- [ ] 연구가 멈춰있지 않은지

#### 이벤트 대응 체크
- [ ] **레이드 (Raid)** 대응 확인
  - 자동 Draft: ☐ 성공 ☐ 실패
  - 전투 완료: ☐ 성공 ☐ 실패
  - 전투 후 Undraft: ☐ 성공 ☐ 실패
- [ ] **겨울 (Winter)** 대응 확인
  - 가을에 식량 비축: ☐ 충분 ☐ 부족
  - 겨울 생존: ☐ 성공 ☐ 실패
- [ ] **화재 (Fire)** 발생 시 AI 대응: _____
- [ ] **탈주 (Escape)** 이벤트 시 AI 대응: _____

## 🔍 상세 체크 항목

### 메모리 누수 확인
- [ ] **ThreatAnalyzer 캐시 크기**: Player.log에서 확인
  - 정상: 1000개 이하
  - 문제: 계속 증가 (ClearCache 미작동)
- [ ] **FoodSubsystem 맵 데이터**: 언로드된 맵 데이터 남아있지 않은지
- [ ] **CombatDefenseSubsystem 맵 데이터**: 전투 종료 후 정리되는지

### 특수 상황 테스트
- [ ] **멀티맵 플레이**: 다른 맵 이동 후 원래 맵으로 복귀 시 정상 작동
- [ ] **저장/로드**: 게임 저장 후 로드 시 AI 정상 작동
- [ ] **모드 설정 변경**: 플레이 중 설정 변경 시 즉시 반영

### AI 무한 루프 체크
- [ ] 같은 작업을 반복적으로 시도하지 않는지
- [ ] 도달 불가능한 위치로 이동 명령 반복하지 않는지
- [ ] 건설 청사진이 무한 생성되지 않는지

## 📌 추가 참고사항

### 정상적인 동작 기준
- **FPS**: 60 근처 유지 (대규모 전투 시 40-50 허용)
- **메모리 증가**: 시간당 30MB 이하
- **틱 지연**: 3배속 유지 가능
- **AI 반응 속도**: 위기 상황 5초 이내 대응

### 성능 개선 버전에서 기대되는 효과
- ThreatAnalyzer 최적화: 전투 시 FPS 10-15% 향상
- FoodAnalyzer 최적화: 대규모 농장에서 20-30% 향상
- ConstructionAnalyzer 최적화: 건물 100개 이상 시 15% 향상
- 메모리 누수 수정: 장시간 플레이 시 메모리 안정화
