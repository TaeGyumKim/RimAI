# RimAI 스토리 시스템 설계 문서

## 개요
RimAI를 단순한 자동화 모드를 넘어 "관찰할 만한 스토리"를 만들어내는 시스템으로 발전시키는 설계입니다.

## 스토리 패턴 (5가지)

### 1. 균형 발전 (Balanced)
- **테마**: 모든 분야 조화롭게 발전
- **특징**: 기본 RimAI 동작
- **우선순위**: Combat(150), Food(100), Construction(80), Research(60)
- **행동 편향**: 모두 1.0x (기본값)

### 2. 요새 콜로니 (Fortress)
- **테마**: 방어와 안전이 최우선
- **특징**: 두꺼운 벽, 많은 포탑, 킬박스, 최소한의 외출
- **우선순위**: Combat(200↑), Food(90), Construction(120↑), Research(70)
- **행동 편향**:
  - 방어 시설 건설: 3.0x
  - 농장 크기: 1.2x (자급자족)
  - 식량 비축: 2.0x (14일치)
  - 방어 민감도: 1.5x (조기 경계)

### 3. 농업 제국 (Agricultural)
- **테마**: 광활한 농장과 식량 생산 중심
- **특징**: 거대한 농장, 식량 과잉 생산, 창고 중시
- **우선순위**: Combat(120), Food(150↑), Construction(90), Research(50↓)
- **행동 편향**:
  - 방어 시설 건설: 0.7x
  - 농장 크기: 2.5x (광활한 농장)
  - 식량 비축: 3.0x (21일치)
  - 방어 민감도: 0.8x (여유로움)

### 4. 유목 생존자 (Nomadic)
- **테마**: 빠른 확장, 최소주의, 효율성
- **특징**: 필수 인프라만 빠르게 건설, 빠른 기술 발전
- **우선순위**: Combat(130), Food(110), Construction(60↓), Research(100↑)
- **행동 편향**:
  - 방어 시설 건설: 0.5x
  - 농장 크기: 0.6x (최소한)
  - 식량 비축: 0.7x (5일치)
  - 연구 속도: 1.5x
  - 최소주의 건설: true

### 5. 기술 연구소 (Researcher)
- **테마**: 빠른 기술 발전과 첨단 장비
- **특징**: 연구 최우선, 고급 장비, 효율성
- **우선순위**: Combat(100), Food(80↓), Construction(70), Research(180↑)
- **행동 편향**:
  - 방어 시설 건설: 0.8x
  - 농장 크기: 0.8x
  - 연구 속도: 3.0x (압도적)
  - 식량 비축: 0.9x

## 스토리 로그 시스템

### 설계 원칙
1. **자연스러운 한국어**: 플레이어가 읽고 이해하기 쉬운 문장
2. **플레이 스타일 반영**: 같은 이벤트도 스타일에 따라 다른 표현
3. **적절한 빈도**: 과도하지 않게, 의미있는 결정만 로그
4. **관람 경험 향상**: 로그만 읽어도 스토리가 느껴지도록

### 로그 카테고리

#### 식량 (Food)
- `Crisis`: "식량 위기 감지! 남은 생존 일수: X일. 농업과 사냥을 최우선으로 전환합니다."
- `Emergency`: "긴급 식량 부족! (X일치) 모든 폰을 식량 확보에 투입합니다."
- `Warning`: "식량 재고 경고. X일치 남음. 생산량을 늘리겠습니다."
- `Surplus`: (Agricultural) "풍요로운 수확! 농업 제국의 창고가 가득 찹니다."
- `WinterPreparation`: "겨울 대비: X일 후 겨울. 식량 비축을 시작합니다."
- `SpringSowing`: "봄이 왔습니다! 대규모 파종을 시작합니다."

#### 전투 (Combat)
- `ThreatDetected`: (Fortress) "적 X명 감지! 방어 태세로 전환합니다. 요새를 지켜냅니다."
- `CombatStart`: "전투 개시! 아군 X명 vs 적군 Y명. 승리를 향해 나아갑니다."
- `CombatVictory`: (Fortress) "전투 종료! (X초) 요새를 성공적으로 방어했습니다."
- `DefenseBuilding`: (Fortress) "방어 시설 건설을 계획합니다. 벽을 높이고 방어선을 강화합니다."

#### 건설 (Construction)
- `BedShortage`: "침대 부족! X개 추가 건설을 계획합니다."
- `InfrastructurePlan`: (Nomadic) "필수 시설만 건설합니다: [건물명]"
- `ExpansionDecision`: (Agricultural) "영토 확장을 계획합니다. 농장을 확장하여 식량 생산을 늘립니다."

#### 연구 (Research)
- `NewResearch`: (Researcher) "새로운 연구 시작: [연구명]. 첨단 기술 개발에 집중합니다."
- `ResearchComplete`: (Researcher) "연구 완료: [연구명]! 과학의 힘으로 한 걸음 더 나아갑니다."
